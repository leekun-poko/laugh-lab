A one-line comedy entry for the One-Liner Laugh Lab: after eating one sock too many, a robot vacuum finally confesses who really took all the missing socks. The program writes that single line to entry.txt in the output directory ($MAKEFUN_OUTPUT_DIR, default /output).

## Run it

```sh
python3 main.py
```
